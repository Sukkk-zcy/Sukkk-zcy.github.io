申请流程

  1. 1

    先添加本站友链

    将上方信息加入你的友链页面，并确保页面可以公开访问。

  2. 2

    填写 GitHub 申请表

    提交站点名称、首页、友链页、描述和头像地址。

  3. 3

    自动校验与人工审核

    机器人检查可访问性和回链；通过后由维护者审核内容，批准后自动添加。

申请要求

  • 已添加本站友链，且友链页面无需登录即可访问。
  • 站点使用域名和 HTTP(S)，不接受 IP 地址或私网站点。
  • 头像地址需能被第三方页面直接作为图片加载；若存在防盗链或访问限制，展示时会使用默认图标兜底。
  • 至少有一篇原创内容，最近一年内有更新。
  • 不含色情、暴力、违法、侵权或其他不适合公开推荐的内容。
  • 长期无法访问、取消回链或内容违规的站点可能被移除。

头像可访问性检测

在提交前粘贴头像地址测试一次。检测会模拟浏览器跨站加载图片，结果仅代表当前浏览器网络环境。
